# Breaking Bad 3D Laboratory (OpenGL & C++)

A 3D interactive computer graphics project built with **C++** and **OpenGL** in **VS Code**, featuring custom shaders, dynamic camera controls, and a card gameplay system.

## Project Structure
- `Breaking Bad/` — Source files, CMake configuration, shaders, and project assets.
- `.vscode/` — Editor build and launch configuration.

## Build & Run
1. Open the project folder in **VS Code**.
2. Configure and build using **CMake** into a local `build/` directory.
3. Run the generated executable.
